Understand the product before trusting it.

Neo Anki keeps its detailed documentation beside the source so behavior, limits, and implementation can change together. Links below point to the current main branch and may be newer than the latest published binary.

Pre-1.0

Project status

Neo Anki is an actively developed desktop preview. The project does not currently make a drop-in Anki replacement claim, a production-readiness claim, or a comparative learning-effectiveness claim.

Desktop releases are public. Browser and mobile implementations are present in the repository, but hosted-service and physical-device release gates remain. Check the exact release notes before relying on a feature.

Release status

No production release yet

Neo Anki is undergoing data-safety, extension-isolation, signing, and cross-platform verification work. Do not download installers offered by third parties.

How releases will work

Official builds will be published only through GitHub Releases. Each release will include signed installers, SHA-256 checksums, a software bill of materials, and build-provenance attestations.

Supported platforms

  • macOS on Apple silicon and Intel
  • Windows x64
  • Linux x64 through AppImage

Supported platforms

  • macOS on Apple silicon and Intel
  • Windows x64
  • Linux x64 through AppImage

Installation and verification

macOS and Windows packages are intentionally unsigned, so the operating system will display a security warning. Follow the installation guide included with each release and update the app manually.

Every release includes SHA-256 checksums, a CycloneDX software bill of materials, and GitHub build-provenance attestations. Verify an artifact with gh attestation verify <artifact> --repo neoanki/neo-anki.

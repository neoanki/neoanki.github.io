Verify before installation

  1. 1
    Download from the official release

    Choose the application artifact, its platform-specific SHA256SUMS file, and the included installation guide.

  2. 2
    Compare the SHA-256 digest

    Use shasum -a 256 on macOS, Get-FileHash on Windows, or sha256sum on Linux, then compare the result with the checksum file.

  3. 3
    Verify GitHub provenance

    With the GitHub CLI installed, run gh attestation verify <artifact> --repo neoanki/neo-anki.

  4. 4
    Install cautiously

    Follow the release’s platform guide. Back up existing data before importing an important collection.

Privacy

Neo Anki is designed as a local-first desktop application. The application does not require an account and does not send your cards, answers, review history, media, or usage analytics to Neo Anki.

Data on your device

Your workspace and backups are stored on your device in locations shown by the application. You control exports and deletion. Your operating-system account and disk protections determine who else can access these files.

Network access

The application does not require network access for studying and does not check for or install application updates automatically. Links you explicitly open, including the releases page, use your default browser.

Extensions

Installed extensions run as trusted code and can receive data through their declared capabilities. Capability declarations communicate intended access; they are not a security sandbox. Review every package and install extensions only from publishers you trust.

Website

This website is hosted by GitHub Pages. GitHub may process connection information according to its own privacy statement. Neo Anki does not add analytics, advertising, cookies, or tracking scripts.

Changes

Material policy changes will be documented with application release notes. Questions can be raised through the public project repository without including private learning data.

Privacy

Neo Anki is device-first and the core desktop study flow does not require an account. Network behavior depends on the optional services and extensions you choose.

Workspace data

The desktop app stores its workspace, media, and automatic recovery backups on your device. Export, restore, and reset actions remain under your control. Your operating-system account, disk encryption, backups, and device security determine who else can read those local files.

Analytics and telemetry

The Neo Anki application does not include product analytics or advertising telemetry. Diagnostic exports are created only when you request one; review them before sharing because they can contain technical details about your environment.

Network features

Studying local material does not require a network connection. The application can make network requests when you explicitly configure encrypted sync, browse the extension catalog, install an approved extension, or open an external link. Application updates are not downloaded or installed automatically.

Encrypted sync sends ciphertext and protocol metadata to the configured sync service. Encryption is designed to keep workspace content from the relay, but an operator can still observe information such as account, timing, request-size, and network metadata. The browser client also shares its unlocked key-use boundary with same-origin code. See the browser sync security boundary and the chosen service operator’s policy.

Extensions

Built-in modules are trusted application code. Installable SDK 2 extensions run in isolated workers and sandboxed frames, and access host features through declared capabilities. An extension granted network:fetch can contact its reviewed HTTPS domains, and other capabilities can expose scoped study or content data. Review every publisher, domain, and capability before installing. A marketplace listing or valid signature does not guarantee safety.

This website

This static website is hosted by GitHub Pages. It adds no analytics, advertising, cookies, form submissions, client-side application code, or third-party assets. GitHub processes connection information under the GitHub General Privacy Statement.

Questions and changes

Material changes should be recorded in this page’s source history and, when relevant, application release notes. Ask public questions in the project issue tracker without including private learning data. Report security-sensitive matters through the private security channel.

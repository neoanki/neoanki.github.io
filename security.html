Coordinated disclosure

Security

Please report suspected vulnerabilities through GitHub private vulnerability reporting. Do not include exploits, user data, or unredacted diagnostics in a public issue.

In scope

  • Desktop main process and preload bridge
  • Persistence, backups, migrations, and importers
  • Application updates and signed release artifacts
  • Extension packaging, loading, isolation, and SDK capabilities

Expected response

We aim to acknowledge reports within three business days and provide an initial assessment within seven days. Disclosure will be coordinated after affected users can obtain a fix.

# Neo Anki website

Static product, documentation, privacy, security, download, and extension-marketplace pages for <https://neoanki.github.io>.

The site intentionally contains no analytics, cookies, client-side application code, or third-party assets. GitHub Actions validates and deploys the static files through GitHub Pages.

Public product claims should distinguish the latest published binary from the current source tree, link to the repository documentation that defines important boundaries, and state pre-1.0 limitations plainly. Update the dated release and marketplace status when either changes.
